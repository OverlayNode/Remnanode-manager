Introduction

__BRAND__ provides a programmable platform for deploying and observing services at the edge. This guide walks you through authentication, your first request and the core objects of the API.

Base URLhttps://__DOMAIN__/v2

Authentication

All requests are authenticated with a project token passed in the Authorization header. Tokens are scoped to a single environment and can be rotated at any time.

$ curl https://__DOMAIN__/v2/projects \
    -H "Authorization: Bearer $API_TOKEN"

Quickstart

Install the SDK for your language and create a client. The SDK retries idempotent requests automatically and exposes typed responses.

import { Client } from "@__BRAND_SLUG__/sdk";

const client = new Client({ token: process.env.API_TOKEN });
const projects = await client.projects.list({ limit: 20 });
console.log(projects.data.length);
